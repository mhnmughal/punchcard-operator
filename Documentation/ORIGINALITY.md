# Originality Audit

_Last updated: 2026-09-06_

Punchcard Operator is checked for structural distinctness from Misprint Department
and any other prior project. The requirement is structural, not cosmetic.

| Area | Punchcard Operator | Distinct? |
|------|--------------------|-----------|
| Core fantasy | Operating a punch-card automation machine — repair the card, load the reader, run the program | Yes — bespoke |
| Screen layout (gameplay) | Machine floor on the left ~62%, vertical punch card on the right, Tool Dock + Load/Execute lever across the bottom, Status Rail across the top | Yes |
| Level select | Card Vault — Program Banks A/B/C as filed cassettes with per-slot rating marks, Training filed separately | Not a plain N-up level grid |
| Progression labels | ACCEPTED / COMPACT CARD / PERFECT PROGRAM (◆ marks) | Own vocabulary |
| Terminology | Control Room, Card Vault, Automation Floor, Status Rail, Tool Dock, Program Bank, carrier, tray, reader, punch/patch/shift/swap/flip/copy | Own vocabulary |
| Verbs | The player edits a program card, not "prints"/"stamps"/"inspects sheets" | Distinct verb set |
| Finale | SYSTEM CERTIFIED — indicator tower, Program Bank plates light in sequence, reader sweep, master-status plate | Bespoke sequence |
| Colour identity | Industrial charcoal panels, manila card, amber machine accent, channel blue/amber | — |
| Typography | Single system face (TMP LiberationSans) used as machine labelling — plates, all-caps read-outs | — |
| Audio identity | Entirely synthesised mechanical transients (punch thud, chad snap, reader ticks, latch, machine-start) — no musical bleeps | Distinct sound world |
| Icon | Tilted punch card with a cut corner + a driven amber punch plunger | Bespoke, no text, no generic code/gear imagery |
| Shared assets with other projects | None — no imported textures, audio, prefabs, or fonts beyond Unity's bundled OFL font | — |

## Notes

- No layout, silhouette, HUD composition, or progression screen was copied from
  another title. The UI is composed from Unity primitives specifically for this
  machine metaphor.
- The one convention shared with most mobile games — a bottom action bar and a
  top status strip — is reframed here as a physical Tool Dock and Status Rail on
  a machine console, not a generic HUD.

Verdict: **PASS** — the game is structurally its own thing.
